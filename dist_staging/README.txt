========================================================================
 👑 WEDDING SONG IMPORTER FOR ADOBE PREMIERE PRO (macOS Edition)
========================================================================

🎯 QUICK START INSTALLATION (1-CLICK):
------------------------------------------------------------------------
1. Double-click "Install.command" in this folder.
2. If macOS prompts "Developer Cannot Be Verified", right-click "Install.command" -> Open -> Open.
3. Open Adobe Premiere Pro.
4. Go to top menu: Window > Extensions > Wedding Song Importer.

✨ FEATURES:
------------------------------------------------------------------------
- 24/7 Zero-Touch Cloud Queue: Clients submit song links on your Studio URL.
- Auto-Import to Bins: Downloads audio at highest quality and imports into organized Premiere Pro Bins automatically.
- Active Project Folder Path Auto-Detection: Saved tracks auto-land right inside your open Premiere Pro project directory.
- Multi-Studio ID Switcher: Change your Studio ID (e.g. "trpworld") inside the panel header to view studio-specific client queues.

🗑️ UNINSTALLATION:
------------------------------------------------------------------------
Double-click "Uninstall.command" to remove all extension files and background services cleanly.
